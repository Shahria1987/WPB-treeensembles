# Data

The experiments use the preprocessed BARC monthly benchmark (24 stations, 1961–2022)
released by Kabir & Chakma on figshare:

**https://doi.org/10.6084/m9.figshare.29876786**

Download the preprocessed CSV from that record and save it in this folder as:

```
data/Preprocessed_Weather_Data_final.csv
```

All scripts read it from this path (`DATA_PATH` at the top of each script).
The data file itself is not stored in this repository.
